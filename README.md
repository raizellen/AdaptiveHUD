INSTRUCTIONS

1. install dependencies by running 'npm install'
2. make a copy of '.env.example' file and rename it as '.env'
3. change the listed IP to your machine's IP address.
4. change to backend directory and run 'npx tsx backend/server.ts'
5. keep the backend running and open a new terminal
6. ensure you are in the root directory and run 'npx expo start'
